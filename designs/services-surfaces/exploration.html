Services 三表面重设计

问题：Services 以什么行模型与分组出现在侧栏（Agents 下方），并让侧栏、托盘浮层、Header 浮层共用同一行模型，使「什么在跑 / 跑在哪个 Pane / 谁启动的」一眼可读。

  • 数据 = 现有只读投影（lsof 10s 扫描 → serviceIndex 归因到 Pane/Project）+ 持久 service Scripts；不新增运行时、不伪造状态。
  • 行模型：品牌彩 mark（proc_brands 60+，补品牌色表）+ 名称 + 等宽端口 + 归属 chip（Agent mark / Script / Manual / Project-wide）+ 绿方块（statusIndicatorService 语言）。
  • 点击 → 跳对应 Pane（panePrefersChat：Agent→Chat、手动→Terminal）；hover ↗ = Preview localhost:port。
  • QuickPanel Services 页重构：Running（新行模型）→ Other listeners（无归属裸端口，诚实降级）→ Scripts（Run）。托盘与 Header 是同一组件的两个锚点。
  • Token 取自 theme.go 实测值（暗/亮），状态含浅色主题翻转验证。
  • 对比与拍板项见同目录 README.md；未选型前不改产品代码。
