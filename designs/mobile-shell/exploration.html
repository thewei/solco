手机外壳:一个会话入口,两种看法

单一决策点:同一个 Agent 会话里,Chat 和 Terminal 在手机上怎么切、怎么融为一体。首页 / 侧栏 / 纯终端三块用户已定,三个方案共用。

已定(不再探索):首页 = 新会话空态 + Composer,「深度思考 / 智能搜索」换成 Agent / Terminal 两个模式芯片;左上角开侧栏(同桌面侧栏的信息结构);点 Agent → 默认 Chat,可切 Terminal;点 Terminal → 整屏终端。

语言来源:Chat = 桌面 chat-view 的 A+B(无容器助手正文、中性 18 圆泡、一行过程摘要、24 圆 Composer、ink 四级);状态槽 = status_indicator.go 的单一槽;键行 = tui-virtual-keyboard-design 的已验证键位。

读法:右栏 Scenes 跳状态;Controls 切主题、终端底色、终端输入形态、键盘;「D · 并排」把三套放在同一场景里对比,每个终端左上角的 cols×rows 是按真实布局量出来的。

最脆弱的假设:手机终端的默认输入是「整行输入 + 键行」(中文 IME 友好,一次 send_input)。若 TUI 菜单类交互(方向键选择)占比高,默认应换成「仅键行」。
