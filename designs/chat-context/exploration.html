Chat · Context window

The composer already draws a context ring (state.contextTokens against a guessed 200k/1M window) with a browser title tooltip. The ask: a real popover like the reference — used / window with a bar and the average cache hit rate.

  • Data that exists: context tokens per message (Claude/Codex/omp transcripts) and history.ReadUsage (input, output, cache read, cache write — one streamed read of the session file, on open, nothing stored).
  • Cache hit rate = cache read ÷ (input + cache read + cache write), whole session.
  • Window: omp/pi list it per model (omp models); Claude/Codex are a guess → shown as “~200k (assumed)”.
  • Not a quota page: no cost, no history, no polling.
  • Compact = the existing /compact text command, sent through the normal prompt path.

Hover the ring (A), click it (B, C). The “Light” button flips the theme.
