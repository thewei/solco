① 接入 · Add Device 入口：页脚弹层里的 “Add Device…”

1
Sheet 三个字段：SSH target（下方给 ~/.ssh/config 别名快捷项，复用 Hosts 页的索引与 sshconfig.ResolveTarget）· Remote session（Auto / Named…；Auto 不传 --remote-session，由 Herdr 在终端里探测：只有一个运行会话就选它，多个则让你选，没有则用 default）· Label（可选，默认 host 或 host/session）。
2
提交前本地校验：target 非空；Label 不与现有 profile 重名（Herdr：默认名被占用时 add 会要求传 --label）。
3
Solco 在 Terminal.app 里执行 herdr machine add <target> [--label L] [--remote-session S]。认证 / 安装 / 重启审批全部在终端里由用户答——Solco 不代答、不存凭据、不开口令弹窗（Herdr 自己也从不弹凭据窗）。
4
Sheet 切到 Waiting：每 2 s 本地读 machine list --json（不走 SSH，便宜）。出现新 profile = 成功。Stop Waiting 只停止等待；之后在终端里完成，设备会在下次打开面板时出现。
5
成功：Toast “Added workbox · Switch”。不自动切换（Herdr：新增设备在后台连接，不改变当前选择）。
!
失败 / 取消：Herdr 不保存 profile（“…machine was not saved”）。Sheet 显示 “Nothing was saved” + 原因，保留已填内容，Try Again。

② 切换 · Switch 事务式：当前设备在切换期间保持可用

Idle点设备 / 会话行
→
Connecting页脚上方出现横幅 “Connecting to X… · Cancel”；当前设备照常可用
→
Committed一次性换上目标的投影；横幅消失
Connecting≤ ~18 s（ssh 取 HOME 8 s + 隧道 ping 10 s）
→
Failed留在当前设备；Toast 说原因 + 动作；只把目标行标成 Attention；不再置全局 offline、不再拉黑整页

取消：点横幅 Cancel、选 This Mac、选另一台设备，都会作废这次切换（Herdr：选 Local 会取消未完成的远端切换，不等对方回复）。

本地会话走同一条事务路径，只是通常 < 1 s，横幅一闪即过（不显示）。

已修的现状缺陷：现在 openInstance 对远端整个拉起过程置全局 loading（禁用变更/拖拽，最长 ~18 s），失败还会把「当前」设备也标成 offline。

③ 恢复 · Recover Solco 不收集任何口令

状态行菜单里的主动作Solco 做什么
Sign-in neededReconnect in Terminal…Terminal 依次执行 ssh -o AddKeysToAgent=yes <target> true && herdr machine reconnect <label>：前一步让口令密钥进 ssh-agent（Solco 的非交互 bridge 只认 agent），后一步让 Herdr 认证并校验已保存设备（不安装/更新）；结束后 Solco 重检，行变 Online → Toast “… is back online · Switch”
Needs attentionSet Up in Terminal…Terminal 执行 herdr --remote <target> [--session S]（Herdr 给出的独立 setup 命令；host key 信任 / 服务器升级在这里审批）
UnreachableCheck Again重跑 machine status <id>；仍失败则保持，不骚扰
DisabledEnablemachine enable <id> → 行进入 Checking… → 回到真实状态

SSH 先行规则：Solco 的 bridge 与 Herdr 后台连接同属“非交互”（BatchMode=yes）。passphrase 保护的密钥必须先进 ssh-agent；失败提示里附 ssh-add 一句，而不是弹口令框。

为什么恢复是两步：Herdr 默认 remote.manage_ssh_config=true，machine reconnect 认证的是 Herdr 私有的 per-attach control socket，Solco 自己的 ssh -L bridge 复用不到。所以先让密钥进 agent（两边都受益），再 reconnect。需要 MFA / 一次性口令的主机，Solco bridge 本轮不支持（需另做 Solco 自有 ControlMaster），行内如实提示。

⑤ 生命周期规则 Herdr 官方语义 → Solco 采用

Herdr 官方（Connecting machines 文档）Solco 行为
“Local opens immediately on startup without waiting for SSH connections.”启动总先进入 This Mac（最近使用的本地会话）；上次的远端设备不再成为首个 bootstrap 目标，避免冷启动卡在 SSH 上
“Selecting Local also cancels an unfinished remote switch.”横幅 Cancel / 选 This Mac / 选别的设备 = 作废当前切换（generation 失效）
“Other machines remain usable.”（一台 Attention 不影响别的）切换失败只标目标行；当前设备与其它行照常
“last workspace and agent state remains visible but dimmed… input disabled… Reconnecting never takes selection away.”连接中断：内容区变暗 + 顶部提示条（“Showing the last known state; input is paused”），不自动跳走，只提供 Switch to This Mac
“Removing or disabling the machine you are viewing returns you to Local.”Forget / Disable 当前设备 → 立即回 This Mac，Toast 说明；现在会留下空白的 “Choose a Session”
“added and enabled machines… connect in the background without changing your selection.”Add 成功不切换，Toast 带 Switch 动作
“Saved profiles contain only opaque ID, label, SSH target, explicit remote session, enabled state. Herdr does not store passwords.”Solco 不存也不收任何凭据；一个设备 = 一个固定的远端会话；同机另一个会话 = 再添加一条（Label 默认 host/session），远端的“Session”只读
“Open clients retry failed connections within 30 seconds.”面板打开时才做状态检查（≥30 s 节流）+ 手动 ⟳ + Add / Reconnect 之后；面板关闭时不做后台 SSH 轮询

侧栏页脚 · 设备 / 会话切换

现状：页脚只有一个 “Session: Default ▾” 系统菜单；远端设备藏在菜单里、状态只有文字后缀；接入是一个不带参数的 Terminal 窗口 + 盲等 20 s；切换失败会把当前设备也标成 offline；Forget 当前设备后整页变成 “Choose a Session”。

Herdr 规则（官方文档已核实）：设备 = 1 条 profile（ID + label + SSH target + 1 个固定远端会话 + enabled），凭据归 OpenSSH；machine add 必须在交互终端完成；启动先开 Local；断线显示变暗的缓存态；禁用/移除当前设备回 Local；新增设备不改变当前选择。

  • A · 单芯片 + 统一面板（推荐）：0 额外高度；页脚只回答“我在哪台设备/哪个会话、它健康吗”，其余全在弹层。
  • B · 设备｜会话 双芯片：与两个概念一一对应；但远端的“会话”是只读的固定值，252px 页脚里两个芯片都被挤。
  • C · 设备轨 + 会话行：一眼看全各设备状态、一键切换；页脚 +36px，对单设备用户是常驻噪声。
