Design Storybook · Git panel
Variants

A · Tabs in the sidebar (shadcn Tabs)

原位精修：视图切换留在侧栏，改成带图标+计数的 shadcn 胶囊 Tabs；头部压成 1 行面包屑。

B · Tabs move to the center toolbar

视图切换上移到中心工具栏（shadcn 线形 Tabs，与工具合并成一行）；侧栏变纯导航，头部 2 行（项目 / 分支选择）。

C · Source list (no tabs)

Changes / Commits 变成侧栏顶部的两个导航行（图标+计数，macOS source list / Fork 形态），没有 Tab 控件。

要解决的 10 个问题

  • Tab 组：纯文字分段、无图标无计数 → 图标 + 计数 + shadcn 形态（用 segmentedTrack/segmentFace 现成脸搭）。
  • 头部：项目/分支/刷新占 2 行 ≈58pt → 1 行 32pt（A/C）或 2 行 58pt 但分支可读性更强（B）。
  • 搜索：常驻且只过滤引用，与 All Commits 的提交搜索同屏两个 → 图标按钮，点击才展开，作用域写进占位符。
  • 单击危险：分支单击即切换、Worktree 单击开 Finder、Remote/Tag/Stash 单击复制 → 单击只选中，双击/Enter 才执行。
  • 提交列表：图谱固定 76 宽，1~2 泳道时圆点到标题隔 ≈50pt → 按真实泳道数自适应宽。
  • 重复：同一 subject 出现 3 次；Stage All 在工具栏与分区头各一份；「Local Changes」标题与 Tab 同名；Total 脚注 → 各留一份。
  • 复制：提交信息不可选、diff 只有 Copy Line → 可选中 + Copy 菜单 + Copy Hunk/Patch。

原型里 Split/Unified 为未改动的占位；所有 Git 动作为模拟。
