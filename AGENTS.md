## Product/runtime boundary

- **Solco is the macOS client/product.**
- **Herdr is the backend/runtime authority** for workspaces, tabs, panes, layouts, terminal sessions, agents, scrollback, persistence, and process lifecycle.
- External Agent conversation history is a separate read-only catalog; it must not become a second runtime. Runtime continuation from history must go through Herdr. The one mutation is the user-initiated, reversible Sessions Trash (2026-10-14), owned only by `internal/sessiontrash`.
- Use mature ownership before custom code: **Herdr API → MyGo native components/official plugins → proven compatible implementation → custom**.
- Do not invent Herdr protocol methods or socket shapes. Inspect the live/actual API.

```sh
GOTOOLCHAIN=auto go tool mygo dev         # run the app
GOTOOLCHAIN=auto go test ./...
GOTOOLCHAIN=auto go tool mygo build   # builds build/darwin-arm64/Solco.app
git diff --check
git diff --cached --check
```

- `go.mod` pins Go 1.27.3 and MyGo v0.6.4 (checked elements: constructors return `ui.Element` values, persistent identity lives in `ui.Handle`); use `GOTOOLCHAIN=auto` so the repository pin does not require changing the user's global Go installation.
- `go.mod` carries a temporary, user-approved `replace github.com/egoist/mygo => ./third_party/mygo` (v0.6.4 plus four vendored deltas re-applied on top: F146/F147 terminal `Options.LocalDragSelect`, WIX-021 field focus delegation — `AutoFocus` on a SearchField/Combobox reaches its inner input — multi-display tray flyout anchoring, and OSC 7501 program-status (`Options.OnProgramStatus`)). Do not remove the replace or add a second framework source; bump the pin and delete `third_party/mygo` only once upstream ships all four. See `third_party/mygo/LOCAL-PATCH.md`. Upstream v0.5.x additions stay unadopted until a task takes them: the Flyout API backs the quick panel (tray + header Agent popover), while `ui.WebView` (official Native-UI-embeddable WebView) does not by itself unfreeze the WebView presentation freeze — that needs an explicit product decision.
- `GOTOOLCHAIN=auto go tool mygo vet .` (ordinary vet + type-aware element/Context checks) belongs in the check set beside `go test`.
- When packaging changes, also build and structurally verify `Solco.app`.

## Scope and ownership

- `internal/nativeui` owns presentation only: shell/titlebar/sidebar/project tree, theme/icons/components, one long-lived MyGo `ui.Router` (persistent Sidebar/Titlebar sit outside the router), per-page files, runtime/watcher/dialog adapters, and visibility-scoped Terminal layout.
- `internal/herdr` owns the Go Herdr CLI/socket boundary: session discovery/bootstrap, RPC, events, direct terminal attach. Keep framework/platform code out of it and out of ordinary domain packages.
- `internal/history` is the read-only history catalog/transcript/live-tailing domain; `internal/sessiontrash` is the only package that moves Provider session files (the Sessions Trash: provider root ⇄ `<userDataDir>/SessionTrash/`, never overwriting, no conversation content in its manifest); `internal/agent` owns Agent product semantics; `internal/gitworkbench` owns the local Git review model; `internal/applog` owns bounded structured logging.
- Herdr `session.snapshot.layouts` remains the Pane topology authority; native UI only maps visible Pane rectangles to official MyGo Terminal elements running supported `herdr terminal attach <terminal_id>`. No client-owned PTY/layout/runtime may appear.
- Automatic attach must never use `--takeover`; hidden Tabs keep no attachment fleet.
- Product decision 2026-10-11: Chat presentation moves onto the official MyGo `ui.WebView` (v0.4.1) over a single bound-service bridge (`mygo.Bind` + streaming channels + typed events; TS client via `mygo generate`). - Product decision 2026-11-01 (Solco's own credentials leave the Keychain, user-approved): macOS binds a Keychain item's access to the code signature of the app that created it, so every rebuild/reinstall with a different signature made macOS ask for the login-Keychain password once per Solco item (Quota tokens, sign-in copies, the commit API key). `internal/secretstore` replaces `mygo.Secrets` for Solco's own entries: one `<userDataDir>/secrets.enc` (0600, atomic rewrite), AES-256-GCM per item with the key name as associated data, the key derived by HKDF-SHA256 from this Mac's hardware UUID (`IOPlatformUUID`) plus a random salt stored in the file — a copied file or backup does not open on another Mac, but it is not a defence against a process running as the same user (the level of `~/.codex/auth.json` and `~/.gemini/…token`). `nativeui.UseSecretsFile` (called from `main.go`) switches it on; without it (headless tests) the store is memory-only and never touches the disk or the Keychain. - Product decision 2026-11-01 (phone connection policy, user-approved; solco-mobile `src/lib/connection-manager.ts`): the phone has one ConnectionManager state machine instead of three scattered recovery paths. Network changes, failures, successes and foreground/background are signals; on a change it races the Mac's routes (a quick direct answer wins at once, relay is the fallback, RTT-scored with a direct bias), retries on a 1/2/4/8/10 s ladder, looks for a better route on a 15/30/60/120 s ladder while on relay, and stays quiet in the background. To tell a quiet path from a dead one the Host's events WebSocket sends `{"t":"hb"}` every 5 s (`internal/remotehost/events.go`; no capability, no golden-file change, older phones ignore the frame); the phone arms its watchdog after the first `hb` and treats 13 s of silence as a dead path. The phone also gains an Android home-screen widget (`react-native-android-widget`) that reads the Host through the app's own client; it shows agent titles and states, never persists a token. Addendum 2026-11-01 (connection hardening, user-approved; client-only, no Host or golden change): a trouble signal that leaves the route unchanged always drops a P2P link (a silent `hb` on a half-open channel used to keep the client on it until WebRTC timed out), and a link that dies within 5 minutes doubles the wait before the next attempt (`p2pAfterTrouble`); a route probe refused with 401 counts as an answer (the revoked phone is forgotten by its queries instead of walking the retry ladder), while a pin mismatch or a relay `502/503/504` without the Host's own error body (`relay_offline`, "The Mac is offline") counts as a dead route and as a connectivity failure; Home's status line names the reason. Addendum (2026-11-01, user-approved): a Host whose LAN/Tailscale address vanishes (DHCP, network change) no longer takes the relay down with it — `Server.Start` brings the relay tunnel up even when the bind fails and still returns the bind error, so paired phones keep connecting through the relay while Settings flags the stale address and pairing stays refused until it is fixed.

## Git safety

- Preserve staged/user changes.
- Do not `git add`, reset, commit, push, or otherwise rewrite user Git state unless explicitly asked.
- Several agents may share this working tree: when you are asked to commit, stage and commit only your own files with `git commit -m … -- <paths>` (never `git commit -a`/`git add -A`), so a parallel session's unfinished edits do not ride into your commit (2026-11-02: a `-a` commit swept a half-finished change into history and left one commit that did not build).
