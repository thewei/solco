## Product/runtime boundary

- **Solco is the macOS client/product.**
- **Herdr is the backend/runtime authority** for workspaces, tabs, panes, layouts, terminal sessions, agents, scrollback, persistence, and process lifecycle.
- External Agent conversation history is a separate read-only catalog; it must not become a second runtime. Runtime continuation from history must go through Herdr. The one mutation is the user-initiated, reversible Sessions Trash (2026-10-14), owned only by `internal/sessiontrash`.
- Use mature ownership before custom code: **Herdr API → MyGo native components/official plugins → proven compatible implementation → custom**.
- Do not invent Herdr protocol methods or socket shapes. Inspect the live/actual API.

## Build and checks

```sh
GOTOOLCHAIN=auto go tool mygo dev         # run the app
GOTOOLCHAIN=auto go test ./...
GOTOOLCHAIN=auto go tool mygo build   # builds build/darwin-arm64/Solco.app
git diff --check
git diff --cached --check
```

- `go.mod` pins Go 1.27.3 and MyGo v0.6.4 (checked elements: constructors return `ui.Element` values, persistent identity lives in `ui.Handle`); use `GOTOOLCHAIN=auto` so the repository pin does not require changing the user's global Go installation.
- `go.mod` carries a temporary, user-approved `replace github.com/egoist/mygo => ./third_party/mygo` (v0.6.4 plus four vendored deltas re-applied on top: F146/F147 terminal `Options.LocalDragSelect`, WIX-021 field focus delegation — `AutoFocus` on a SearchField/Combobox reaches its inner input — multi-display tray flyout anchoring, and OSC 7501 program-status (`Options.OnProgramStatus`)). Do not remove the replace or add a second framework source; bump the pin and delete `third_party/mygo` only once upstream ships all four. See `third_party/mygo/LOCAL-PATCH.md`. Upstream v0.5.x additions stay unadopted until a task takes them: the Flyout API backs the quick panel (tray + header Agent popover), while `ui.WebView` (official Native-UI-embeddable WebView) does not by itself unfreeze the WebView presentation freeze — that needs an explicit product decision.
- `GOTOOLCHAIN=auto go tool mygo vet .` (ordinary vet + type-aware element/Context checks) belongs in the check set beside `go test`.
- When packaging changes, also build and structurally verify `Solco.app`.

## Scope and ownership

- `internal/nativeui` owns presentation only: shell/titlebar/sidebar/project tree, theme/icons/components, one long-lived MyGo `ui.Router` (persistent Sidebar/Titlebar sit outside the router), per-page files, runtime/watcher/dialog adapters, and visibility-scoped Terminal layout.
- `internal/herdr` owns the Go Herdr CLI/socket boundary: session discovery/bootstrap, RPC, events, direct terminal attach. Keep framework/platform code out of it and out of ordinary domain packages.
- `internal/history` is the read-only history catalog/transcript/live-tailing domain; `internal/sessiontrash` is the only package that moves Provider session files (the Sessions Trash: provider root ⇄ `<userDataDir>/SessionTrash/`, never overwriting, no conversation content in its manifest); `internal/agent` owns Agent product semantics; `internal/gitworkbench` owns the local Git review model; `internal/applog` owns bounded structured logging.
- Herdr `session.snapshot.layouts` remains the Pane topology authority; native UI only maps visible Pane rectangles to official MyGo Terminal elements running supported `herdr terminal attach <terminal_id>`. No client-owned PTY/layout/runtime may appear.
- Automatic attach must never use `--takeover`; hidden Tabs keep no attachment fleet.
- Product decision 2026-10-11: Chat presentation moves onto the official MyGo `ui.WebView` (v0.4.1) over a single bound-service bridge (`mygo.Bind` + streaming channels + typed events; TS client via `mygo generate`). The bridge is presentation-only — the conversation runtime, Agent semantics and every Herdr method stay untouched, and the page may only ever talk to its own bridge from the app content origin (`mygo://localhost` embedded by `mygo build`; no localhost HTTP backend, no private AppKit embedding). History/Terminal/Git surfaces stay Native UI until a separate explicit task moves an HTML-suited piece of them; the native Chat implementation is retired only at acceptance parity.
- Product decision 2026-10-13 (narrowed 2026-10-14): the `/files` preview center renders text and code natively in MyGo's `ui/editor` (read-only `editor.View`; the 8 MiB `filesview.TextPreviewCap`), while the official `ui.WebView` over a strictly read-only `filesPreview` bridge renders only Markdown and web images (the page has no mutation channel and refuses text). The file tree stays native and gains ignore rules (fixed heavy/generated names + git-owned ignored paths, "Show ignored files" toggle) and bounded local file operations (new file/folder, rename, delete with explicit confirm) owned by `internal/filesview` — no second Git runner, no new Herdr method.
- 0.10 target: Lazygit is removed. `/workspace` has one local `WorkspacePrimarySurface` owner for Terminal / Chat / Diff Review / Commit. **No right sidebar:** `/files` is a view destination opened from the sidebar's top view tabs (Changes / Sessions / Files / Hosts), with an ignore-aware, action-carrying file tree in the left sidebar and a native code view (`ui/editor`; WebView for rendered Markdown and images) in the center; Scripts and Services belong to the existing Header Agent activity popover's Services tab. Godiff is a UI/behavior reference only; do not copy/import its `internal/*` implementation.
- Product decision 2026-10-26: `internal/workboard` is the capability gate for one named plugin, `herdr-projects`, whose task board Solco presents natively (palette entry → Header popover Tasks tab → `/tasks`). The plugin stays the task authority and is reached only through its own CLI and Herdr's plugin commands; every surface and call is hidden until `herdr plugin list --json` reports it installed, enabled and in the verified `1.2.x` window, and always on remote instances. This is the only exception to "plugin UI"; see `docs/client-product-architecture.md`. On 2026-10-26 the user explicitly authorized a native Settings page for that plugin's own settings (`/settings/workboard`, shown only while the gate is open, driven by `show --json` / `set` / `unset`; voice, Web UI, cross-machine and key settings stay out) plus the management surface (archive/restore/clear, coordinator restart/new/stop, autopilot, automations on/off/run/remove, plan approval, richer New Task). Plugin semantics, validation and refusals stay the plugin's; Solco copies no option sets.
- Use MyGo native widgets before custom drawing; reuse `theme.go`, `icons.go`, and `components.go` before adding one-off page styling.
- Native window contracts: ⌘W closes the focused Tab through the shared close-tab confirm — never the window; the native window title mirrors the current route via `Shell.syncWindowTitle` (Workspace stays the bare app name).
- Logs are structured and size-bounded under MyGo `PathLogs` (2 MiB active + 3 backups by default). Never log terminal bytes/output, prompt or conversation bodies, credentials, auth headers, provider secrets, or environment dumps; log operation names, stable runtime IDs, errors, state counts, and timing.
- Keep MyGo pinned exactly until an explicit framework upgrade is verified.
- Product decision 2026-10-26 (view switch): Settings → Work Board carries a `Native | Board` switch (`General.WorkboardView`, default **Board**). Board: every Project/task row and native-page entry opens the plugin's own board Tab (`openWorkBoard`); Native: Solco's `/project`, `/task`, `/archived` pages, kept under trial until the user releases them by changing the default. The switch exists only while the plugin gate is open; both views read the plugin's CLI and never a second store.
- Product decision 2026-10-29 (shadcn alignment, phased, presentation only): the UI follows shadcn's shapes and interaction states while keeping Solco's own tokens and type scale. Phase 1 (title bar): the breadcrumb is ghost chips with independent chevron separators; every route's page Actions is a bare `⋯` icon button at the head of the trailing tools (same spot everywhere, the Changes view's Git tools — file list toggle, Fetch/Pull/Push, Split/Unified — sit just ahead of it in the same header since 2026-10-30, with the Git actions merged into its menu, instead of a toolbar row above the diff); icon-button corners are 8 on the 28/24 tiers (`iconButtonRadius`); an icon button with nothing to do (Back/Forward at the history's ends) is half strength with no hover face. Stroke stays 1.5, inner-page 20pt titles are untouched until their own review (Phase 5), menus stay the system `NSMenu`. Phase 2 (tooltips): every tooltip is `tipped(...)` in `internal/nativeui/tooltip.go` — the nova face (radius 8, padding 6×12, no shadow, inverted colors, a Painter-drawn arrow aimed at the anchor, Kbd chips for shortcuts, and the chips are spelled from the shortcut binding that really fires); no other file calls `Element.Tooltip` or `ui.TooltipBase`. MyGo keeps the tooltip timing and placement; popovers keep MyGo's default face; tooltips MyGo draws inside its own components (e.g. the editor's find bar) are unchanged. Phase 3 (controls): `internal/nativeui/controls.go` is the one owner of the control faces — `regularButton`/`regularPrimaryButton` (the primary carries the 1px border MyGo leaves off, transparent, so a row of buttons is one height), `textField`/`textArea`/`searchField`/`comboField`/`selectField`/`segmentedControl` — which wrap MyGo's own controls with the theme corner (`Theme.Radius = Radius().Row`, 8). The focus ring stays MyGo's own — 2px, one pixel off the edge, a field only recoloring its border — and the faces neither paint nor switch it off (`TestControlsDrawNoFocusRing`): shadcn's flush 3px halo was built and tried on 2026-10-29, and the user kept the original, slimmer ring. No other file calls `ui.Button`/`PrimaryButton`/`TextInput`/`TextArea`/`SearchField`/`Combobox`/`Select`/`Segmented` or restates a control's radius, border, background, padding or ring (`TestControlsHaveOneFace`). `ui.NumberInput`, `Checkbox`, `Switch` and `Slider` keep MyGo's own face. Later phases — sidebar rows, inner-page titles, palette — each need their own review.
- Product decision 2026-10-30 (device & session switcher, user-approved; design in `designs/sidebar-footer-switcher/`): the sidebar footer is one chip plus one panel holding This Mac's Herdr sessions and the saved Herdr machines ("devices"). A device profile exists only in Herdr (`herdr machine …`); Solco keeps in-memory observations (verdict, shared SSH connection, last failure) and never a device registry or a credential. Add is a Terminal handoff of `herdr machine add` polled through the local `machine list`; a `~/.ssh/config` alias is passed as typed. Switching is a transaction over an SSH bridge that forwards both the Herdr API socket and the sibling `-client.sock` (`internal/herdr/bridge.go`): the window keeps its device until the dial succeeds, failure/cancel changes nothing and offers Sign In / Set Up / Check Again; Sign In is Solco's own OpenSSH ControlMaster (`internal/herdr/sshcontrol.go`, started in the user's Terminal, MFA-capable, secrets never seen). Launch always opens This Mac; Disable/Forget close the device's bridge after the window leaves it; automatic attach still never uses `--takeover`. Entry points: footer panel, Hosts register, Command Center Devices.
- Product decision 2026-10-30 (Quota page — named Usage until the same day —, user-approved; design in `designs/usage-page/`): `/quota` (Sessions sidebar third row; settings at `/settings/quota`; `migrateRoute` carries old persisted `/usage` routes over; Go identifiers, `internal/usage` and the `usage.<id>.token` Keychain keys keep their names) shows each agent's own quota windows for Claude Code, Codex, Cursor, Zhipu GLM, GitHub Copilot and Antigravity, owned by `internal/usage` (read-only, no framework code) and presented by `internal/nativeui/page_usage.go`. Every provider is opt-in per provider and contacts only its own host; reading another app's sign-in (Claude Code's Keychain item, Cursor's own token from cursor-agent, `gh auth token`, Antigravity's saved Google OAuth sign-in) happens only after an explicit consent dialog unless the user pasted a token of their own; tokens live only in `mygo.Secrets` (`usage.<id>.token`), never in settings files or logs. Reads happen when the page opens, when the Header popover's Quota tab opens (a TTL-cached `refreshUsage(false)`) or on manual Refresh — no background polling, no cost estimates, no threshold notifications, and no recorded history (the 30-day strip is recomputed from the existing Claude Code/Codex session files by `internal/history/usage_daily.go`). Antigravity (user-chosen default source, 2026-10-30, Google-terms risk accepted by the user and restated in the consent dialog) reads its quota offline from Google's cloudcode-pa API with Antigravity's own saved sign-in (`~/.gemini/…` token file, else Keychain `gemini/antigravity`), refreshing in memory only and never writing back; without the user's yes (`Usage.SignInAllowed`, cleared with the provider switch) it asks only the running app's local server. Cards pick their layout from the data: a counted allowance is a hero number (Cursor's 500 requests), model groups are titled compact rows (Antigravity), sub-limits are compact rows, other windows are plain bars, and facts without a bar (reset credits, extra usage) are chips.
- Product decision 2026-10-30 (agent surfaces, user-approved; design in `designs/agent-surfaces/`, presentation only): (1) ONE status indicator (`internal/nativeui/status_indicator.go`) draws every agent/tab/project/pane state — a 16pt slot at the row's right end, working = spinner, idle/resolved = hollow ring, otherwise a solid dot, nothing known = empty slot; nobody paints a corner dot or a private spinner. (2) The Header Agent popover is `segmentTabs` (same face as Git Changes/Commits) with Agents / Quota / Services / Tasks; its trigger reads `waiting/total` (waiting = attention + review + tasks needing a human; total = listed agents + such tasks without an agent); the Quota tab shows mini cards from the `/quota` data. (3) Sidebar Agents are grouped under a faint Workspace label with a last-worked time (client-observed transitions ∪ session-file mtime) before the indicator; Workspace rows are tiles (letter tile; fixed meta columns for branch — amber when the tree is dirty, so there is no second dot — and pane tally; the one dot at the row's edge is only the state slot: green = a service/daemon is running under it). (4) Sub-agent nesting is read-only from Claude Code's own `<session>/subagents/agent-*.jsonl|.meta.json` (`internal/history/subagents.go`; active = written within 20 s; a vanished/changed layout degrades to the flat list; Herdr has no parent info and gains none). (5) The focused pane card's ring is neutral (`text@0.5`), never blue. (6) Settings → General → Window → "Show Tabs in Sidebar" (default **off**, user-set 2026-10-30; `General.TabsPlacement` ""|"titlebar" = Tab bar, "sidebar" = tree): off puts a browser-style Tab bar (`tabbar.go`: per-tab brand mark, state slot, hover ×, overflow scroll with ‹ › and the selected tab scrolled into view, + new tab) in the breadcrumb's place on `/workspace`, and the sidebar tree lists Workspaces only; tabs stay Herdr's (select/close-confirm/new via the existing paths).
- Still forbidden: a second Solco runtime implementation, a mode switch (the `herdr-projects` Native | Board view switch above is the one named exception), Notes/Bookmarks/Annotation, plugin UI/marketplace (the `herdr-projects` work board above is the one named exception), cloud accounts, telemetry.
