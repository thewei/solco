Rig: isolated `SolcoAcc.app` (com.whstudio.solco.acc), real Herdr, real OMP with the fixture model, a throw-away git repo; driven with Computer Use. No phone/Android.

## What was exercised (all through the Assistants page, no CLI shortcuts)

| Step | Observed | DB / git evidence |

## Findings

1. **F-proof-stale (fixed).** Proof box read once on open and kept "No evidence has been collected yet." after the review started. It now re-reads while open whenever the task's revision/state/reviewState changes (`frontend/src/assistants/Proof.tsx`, `stamp`).
2. **F-merge-fact (fixed, RED first).** After Merge the progress strip still said "Verifying review … is ready": `review.merged` / `review.rejected` wrote no ledger fact. Standalone tasks now record merged → `verified`, rejected → `run_finished` (`supervisor.go`, `TestMergedAndRejectedReviewsLeaveTheirOwnFact`). `changes_requested` is followed by the resumed run's own events, so it is not mapped.
3. Rig recipe gaps (in LESSONS): the demo repo needs an initial commit before a coding task can start; the plugin binary must be built inside the rig worktree.
