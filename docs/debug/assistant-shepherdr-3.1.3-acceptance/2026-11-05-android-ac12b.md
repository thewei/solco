## Findings

- No product defect found in this round. The Behavior page needs an explicit Save (the earlier "no write" was the draft state, not a lost write).
- Harness facts worth keeping: `adb exec-out screencap` on this device lags the real screen by 10–25 s, so every phone assertion was made against the core and the log, with the screenshot only as corroboration; `adb input tap` fired blind lands on whatever is on screen when the phone catches up, so never queue taps.
