## 本次发现（未修）

1. **Coordinator 启动简报以"用户消息"形式出现在 Assistant 对话里**（`Solco-Run-Id: … You are the Coordinator…`，132 行，需展开）。Assistant 页应是用户与 Assistant 的对话，系统简报不应作为用户发言展示。归属 U01/U06。需要产品决定：隐藏、折叠成"系统指令 r1"芯片，还是保持现状。
2. 当 Herdr/chat-stream 身份缺失时，Chat 页只显示 "Working…"，没有"为什么没出内容"的说明或超时降级（对应 C02 capability doctor 缺口）。真实用户环境有这两个扩展，所以只在装机不完整时出现。
3. 系统弹出 "SolcoAcc Notifications" 权限提示，属于首次通知授权；未授权，未测桌面通知送达。
