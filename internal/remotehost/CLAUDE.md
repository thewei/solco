config.go: 监听策略纯数据层——Mode（off/loopback/lan/tailscale，零值即 off，未知值报错而不放宽）、Config.Validate/ListenAddr（lan 只认私网/链路本地单个网卡地址，tailscale 只认 100.64/10 与 fd7a:115c:a1e0::/48，永不返回 0.0.0.0/::，不开 socket）

pairing.go: 一次性配对码（128 位 base32、6 分钟、单次、同一时刻只有一个活动码、常量时间比较；配对码不是可复用凭据，绝不写日志）
devices.go: 已配对设备库 DeviceStore（devices.json 0600，只存 token 的 SHA-256 + 名称 + 时间；明文 token 仅 Add 返回一次；Authenticate 常量时间、LastSeen 一分钟节流写盘；Revoke 即刻失效并回调关闭该设备连接；损坏文件报错而不是静默解除全部配对）
backend.go: Host 与 Herdr 之间唯一的小接口 Backend（本机 Session 列表/投影/事件订阅/pane.send_input/observe 命令）与 EventSource，NewManagerBackend 适配 herdr.Manager；instance、pane、terminal 都要先在这里解出才进 socket 路径或 argv
tree.go: 投影 → /api/v3/tree 线格式（BuildTree：全不透明 ID、保持 Herdr 顺序、不含聚焦字段；Agent 带 title＝桌面侧栏算好的会话标题→name→provider 显示名、lastActiveMs＝桌面的最近活动时间，由 Options.AgentFacts 快照转发，Host 不重新解析会话文件，无快照（桌面未显示的 Herdr session）时只给 provider 显示名）、Agent 的 background[]（子代理 + 本 pane 服务，桌面 remoteBackground 算好，Host 只转发）、内容哈希（标题变化会推进 revision）与 paneForTerminal/paneIDs
server.go: Server（New/Start/Reconfigure/ListenAddress/serve/Close/Handler/StartPairing/RelayStatus；Reconfigure(cfg, relay)=先关 relay 隧道、监听与全部 WS、作废配对码，再按新配置绑定，失败即保持停止，绝不回落到更宽的地址；同口重绑经 listenReliable 短重试躲开 darwin 关闭滞后，绝不放宽地址）：TLS 1.3 + 指纹、POST /pair（免鉴权）、bootstrap（lan/tailscale 监听中带 `net.addresses`＝当前正在服务的那个地址，loopback/绑定失败不带——不真实 serving 的地址绝不下发；golden bootstrap-net.json）、tree（ETag=内容修订）；authorize(scope)+guard 是唯一鉴权入口（Bearer 头或 ['solco.bearer', token] 子协议，或 wopen 无子协议场景的 ?token= query——与 /chat/files 的搜索词同名，带头时头优先；query 绝不进日志）；Scope 位（view/terminal-input/manage，V1 全授）；撤销经 OnRevoke 异步关闭该设备所有 WS（不阻塞 Settings；先发 close 帧再取消，取消 ctx 会让库不发帧就断连）；instance 必须是 Backend 的本机 Session；relay 隧道在 Relay.Enabled 时随 serve 拉起；监听绑定失败（LAN 地址随 DHCP/换网消失）时 Start 仍拉起 relay 再返回绑定错误——relay 外拨并经自己的 127.0.0.1 桥进 Handler()，已配对手机继续可达，Settings 照常标红过期地址、StartPairing 因无监听器拒绝，StartPairing 在 relay 开启时给 QR 追加 &r=&rt=（secret 缺失只记警告不阻塞配对）；DeviceOnline(id)=该设备此刻是否持有活动 socket（Settings 的 Online 标记）；Close 同时停地址看门狗并等它退出（netStop/netDone）
watch.go: 地址看门狗与 net 广播——watchAddresses（Start 拉起、Close 停止并 join）每 netWatchInterval（包变量，测试可缩短）跑一次 checkAddress：lan/tailscale 配置地址不在 Candidates 里而网卡有可用地址时回调 Options.OnAddressLost（每次报告一个独立 goroutine——回调要跳 UI 线程，而 Close 会 join 看门狗，同步回调会互锁；候选为空＝没地方可去，静默，relay 继续服务；loopback/off 不看）；真正的换址/落盘/重绑归回调方（nativeui remoteAddressLost → setRemote → Reconfigure，单一重绑路径），Host 自己绝不换地址；advertised() 只广播当前正在服务的那个地址（listenHost/listenPort），绑定失败什么都不广播
